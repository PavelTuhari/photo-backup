PhotoBackup

Копия фотоальбома с этого Mac: снимки по годам, база Photos в архиве, скрипты восстановления и просмотр.

Монтирование

bash scripts/mount_backup.sh
bash scripts/unmount_backup.sh

Первая команда печатает точку монтирования, обычно /Volumes/Photos. Повторный запуск не подключает образ второй раз.

Повторить экспорт

Год берётся так: ZDATECREATED + 978307200 + ZTIMEZONEOFFSET, затем gmtime. Имя файла — исходное имя из базы. Повторы в одном году получают суффикс _2, _3. Запрос к базе без ORDER BY. Его нельзя сортировать.

python3 scripts/export_photos.py \
  --library "$HOME/Pictures/Photos Library.photoslibrary" \
  --media /Volumes/Photos \
  --archive Photos-library-other.tar

Восстановить альбом Apple

python3 scripts/restore_photos_library.py --dry-run
python3 scripts/restore_photos_library.py
open -a Photos "/Volumes/Photos/Restored Photos Library.photoslibrary"

По умолчанию библиотека собирается внутри смонтированного образа. Файлы клонируются через cp -c и не занимают вторые 114 ГБ. На внутренний диск эту копию класть нельзя: там нет столько свободного места.

Приложение

Откройте Photo Backup.app в этой папке. Слева годы, справа сетка. Клик открывает снимок или видео, стрелки листают. Миниатюры делает QuickLook, снимки читает ImageIO, видео играет AVKit. Это те же системные механизмы, которыми Photos показывает файл. Сама сетка не использует PhotoKit: PhotoKit видит только системную библиотеку, а не произвольную папку. Собрать заново: bash scripts/build_app.sh.
